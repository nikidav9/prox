# Gemini Agents

Мульти-агентное веб-приложение на Next.js с Google Gemini.

## Агенты

- 🔍 **Исследователь** — факты и анализ
- ✍️ **Писатель** — тексты и контент
- 💻 **Программист** — код и технологии
- 📊 **Аналитик** — данные и выводы

## Запуск

1. Получи API ключ на [aistudio.google.com](https://aistudio.google.com)
2. Создай `.env.local`:
   ```
   GEMINI_API_KEY=твой_ключ
   ```
3. Установи зависимости и запусти:
   ```bash
   npm install
   npm run dev
   ```
4. Открой [http://localhost:3000](http://localhost:3000)
